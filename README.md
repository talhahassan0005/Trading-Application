# Trading-Application

| Folder | What it is |
|---|---|
| [`mobile-app/`](mobile-app) | Trynex — the customer trading app (Expo / React Native, Android + iOS) |
| [`admin-panel-web/`](admin-panel-web) | Vertex Admin — the staff back office (React + Vite web app) |
| [`supabase/`](supabase) | Shared backend: database schema, access rules and setup guide |

Both apps use the same Supabase backend for sign-in/sign-up, KYC verification, account
freezing and account-deletion requests. **Start with [`supabase/README.md`](supabase/README.md)**
to set it up.
